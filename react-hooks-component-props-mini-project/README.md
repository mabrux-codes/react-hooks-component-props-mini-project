# React Hooks Component Props Mini Project

This project is a simple React application that demonstrates the use of functional components and props. It includes a Header, About section, a list of articles, and individual article components.

## Project Structure

```
react-hooks-component-props-mini-project
├── src
│   ├── components
│   │   ├── Header.js        # Header component displaying the blog name
│   │   ├── About.js         # About component displaying information and an image
│   │   ├── ArticleList.js    # ArticleList component displaying a list of articles
│   │   └── Article.js       # Article component displaying individual article details
│   ├── App.js               # Main application component
│   ├── index.js             # Entry point of the application
│   └── styles
│       └── App.css          # Styles for the application
├── package.json              # npm configuration file
├── .gitignore                # Git ignore file
├── README.md                 # Project documentation
└── public
    ├── index.html           # Main HTML file for the React application
    └── favicon.ico          # Favicon for the application
```

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd react-hooks-component-props-mini-project
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the application, run:
```
npm start
```
This will launch the application in your default web browser.

## Components

- **Header**: Displays the name of the blog.
- **About**: Shows an image and a brief description about the blog.
- **ArticleList**: Renders a list of articles.
- **Article**: Displays the title, date, and preview of an individual article.
